# Brand explorations

Exploration only. These pages sit beside the live site and do not replace it. `index.html` and the other live pages are unchanged.

Branch: `cursor/brand-explorations-6ac7`

Each file is a standalone page: the homepage hero, then the four-stage section “Where this goes,” using the copy on `main`. The hero visual is typographic. There is no product mockup, no nautical mark, and no photograph.

## Direction A — Midnight Signal

A near-black field and one gold signal, set in a sharp modern serif, so the practice feels precise and quiet.

- Palette: ground `#081018`, ink `#EDEAE3`, body `#C9D0DA`, muted `#A9B4C4`, line `#546478`, signal `#E6C15A`
- Fonts: Instrument Serif (headlines), Instrument Sans (text and wordmark)
- Spacing: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128
- Icons: sharp 1.25px square-cap instrument marks
- Preview: https://htmlpreview.github.io/?https://github.com/alexjburk/Buoy22-site/blob/cursor/brand-explorations-6ac7/brand-explorations/directionA.html

## Direction B — Board Paper

Warm paper, ink, and hairline rules, set like an annual report, so the numbers read as a board document.

- Palette: desk `#E3DCD0`, paper `#F4F0E6`, ink `#161513`, soft `#3E3934`, muted `#5C564E`, rule `#8F877C`, accent `#8C3B32`
- Fonts: Newsreader (headlines and wordmark), Libre Franklin (text)
- Spacing: 6, 12, 18, 24, 36, 48, 72, 96, 144
- Icons: small letterpress index marks
- Preview: https://htmlpreview.github.io/?https://github.com/alexjburk/Buoy22-site/blob/cursor/brand-explorations-6ac7/brand-explorations/directionB.html

## Direction C — Private Office

Deep green and cream, a small-caps wordmark, and wide margins, so the practice feels like a private office.

- Palette: green `#1B3328`, spine `#14281F`, cream `#F6F1E6`, ink `#1A2420`, muted `#3C4A42`, brass `#D4B56A` (on green), brass ink `#6E5532` (on cream)
- Fonts: Cormorant Garamond (headlines), EB Garamond (text and small-caps wordmark)
- Spacing: 8, 16, 24, 40, 64, 96, 128, 160
- Icons: thin intaglio seals
- Preview: https://htmlpreview.github.io/?https://github.com/alexjburk/Buoy22-site/blob/cursor/brand-explorations-6ac7/brand-explorations/directionC.html
